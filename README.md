#  Sales Data Analysis Using PostgreSQL

## Project Overview
This project uses PostgreSQL to analyze sales transactions and evaluate business performance through SQL queries. It demonstrates relational database design, data aggregation, and KPI analysis to generate insights into revenue, profitability, and business growth.

## Database Structure
The database consists of four related tables:
- **Customers:** Customer details, cities, channels, and signup dates.
- **Products:** Product categories, unit costs, and list prices.
- **Orders:** Order dates, statuses, and payment methods.
- **Order Items:** Quantities, transaction prices, and discounts.

## Tools & SQL Skills
- PostgreSQL and relational database design
- Primary and foreign keys
- `INNER JOIN` and `LEFT JOIN`
- Aggregations, filtering, and grouping
- Common Table Expressions (CTEs)
- Window functions: `LAG()` and rolling averages
- Date functions and analytical views

## Business Analysis
The project covers:

- **Annual performance:** Revenue, gross profit, profit margin, completed orders, and average order value (AOV).
- **Business growth:** Year-over-year revenue and order growth.
- **Monthly trends:** Month-over-month growth, year-over-year growth, and three-month moving averages.
- **Product categories:** Revenue, gross profit, contribution percentages, and profit margins.
- **City performance:** Customer counts, revenue contribution, revenue per customer, and AOV.

## Business Value
The analysis helps identify profitable product categories, evaluate geographical performance, monitor business growth, and support data-driven decisions.
